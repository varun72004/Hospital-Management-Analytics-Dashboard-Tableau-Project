# 🏥 Hospital Management Analytics Dashboard | Tableau Project

An interactive Healthcare Analytics Dashboard built using Tableau to help hospital management monitor patients, doctors, appointments, treatments, billing, and overall revenue performance through data-driven insights.

## 📌 Project Objective

The goal of this project is to analyze hospital operations and improve decision-making using interactive visual dashboards. The dashboard provides insights into patient trends, doctor performance, revenue generation, appointment management, and operational efficiency.

---

## 📊 Dashboard Features

### ✅ Executive KPIs
- Total Patients
- Total Revenue
- Total Appointments
- Total Doctors

### 👨‍⚕️ Doctor Analytics
- Doctor-wise Appointments
- Revenue by Specialization
- Appointments per Doctor

### 🧑‍🤝‍🧑 Patient Analytics
- Patient Age Distribution
- Gender Analysis
- Repeat Visit Analysis

### 💰 Billing & Revenue Analytics
- Treatment Revenue Analysis
- Pending Payments
- Payment Method Analysis

### ⚙️ Operational Analytics
- Appointment Completion Rate
- Peak Traffic Analysis (Monthly/Daily Trends)
